# PDF Generation Rules
1. Build PDF templates using HTML and CSS.
2. Render PDFs using Playwright/Chromium.
3. Base the layout tightly on the visual reference. Do not replace the design with a generic invoice template.
4. Ensure pagination handles arbitrary numbers of products cleanly.
5. PDF Generation must not depend directly on AI. All data should be deterministic at the time of rendering.
